# Product

## Register

product

## Users

Developers who use multiple AI coding assistants on macOS and need one dependable place to connect provider accounts, inspect quota, run CLIProxyAPI, and configure local CLI agents.

## Product Purpose

Quotio is a native macOS command center for CLIProxyAPI. It makes account, quota, proxy, and agent state legible and actionable without forcing users to inspect provider files or manage each CLI independently. Success means users can understand availability at a glance and safely change local configuration with clear feedback.

## Brand Personality

Native, compact, trustworthy. Quotio should feel like a capable macOS utility that stays out of the user's way while making complex multi-provider state understandable.

## Anti-references

Avoid web-dashboard imitation, ornamental data visualization, and unfamiliar controls that fight macOS conventions. Do not trade quota accuracy or operational clarity for decorative polish.

## Design Principles

- Make operational state truthful at a glance, including unknown, unavailable, and stale data.
- Prefer familiar macOS behaviors and controls over invented interaction patterns.
- Keep dense multi-provider information calm, compact, and scannable.
- Put safety and reversibility ahead of speed for credentials, configuration, and lifecycle actions.
- Preserve a coherent experience across the main window and menu bar.

## Accessibility & Inclusion

Support macOS light and dark appearances, Dynamic Type-compatible system typography, VoiceOver labels for icon-only controls, keyboard access, reduced motion, and state indicators that do not rely on color alone. Keep all user-facing text in the existing localization system.
